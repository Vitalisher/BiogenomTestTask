Проект "BiogenomNutrition" — это веб-приложение на ASP.NET Core, созданное для предоставления персонализированных отчётов о питании и рекомендаций по добавкам. Оно помогает пользователям отслеживать уровень потребления питательных веществ и получать советы по устранению дефицитов через удобный API. Основные функции включают генерацию отчётов с данными о дефицитах и достатках, анализ нутриентов и рекомендации добавок.
