Проект BiogenomNutrition представляет собой веб-приложение на основе ASP.NET Core, разработанное для предоставления персонализированных отчётов о питании и рекомендаций по добавкам. Проект ориентирован на пользователей, желающих отслеживать уровень потребления питательных веществ и получать рекомендации по устранению дефицитов. Проект реализован с использованием современных технологий и архитектурных подходов, обеспечивая масштабируемость, читаемость и удобство поддержки.Основные функцииГенерация отчётов: Пользователь получает отчёт о текущем уровне потребления питательных веществ, включая количество дефицитных и достаточных элементов, основанный на последних данных.

Отчёт доступен через API-эндпоинт и включает дату создания, количество дефицитов и достатков.

Анализ питательных веществ:Система предоставляет детализированную информацию о каждом нутриенте: название, текущее значение, единицы измерения, норма, процент выполнения и статус (дефицит или достаток).
Данные доступны через отдельный эндпоинт с возможностью обновления значений с учётом добавок.

Рекомендации по добавкам:На основе анализа отчёта система предлагает добавки с указанием названия, изображения и описания.
Эндпоинт возвращает список рекомендованных добавок, связанных с конкретным отчётом.

Преимущества и шаблоны:Пользователь может получить HTML-шаблон с преимуществами использования системы, который генерируется на основе предопределённых данных.

АрхитектураПроект построен по принципу Clean Architecture с разделением на слои:Domain: Содержит сущности (например, NutritionReport, Nutrient, Supplement) и интерфейсы репозиториев (INutritionReportRepository).
Application: Включает DTO (например, NutritionReportDto, ContentTemplateResponse) и сервисы (NutritionReportService), реализующие бизнес-логику.
Infrastructure: Реализует репозитории (например, NutritionReportRepository) и контекст данных (NutritionDbContext) с использованием Entity Framework Core и PostgreSQL.
API: Содержит контроллеры (например, NutritionReportController) и конфигурацию приложения (Program.cs), построенную на современном подходе без Startup.

ТехнологииФреймворк: ASP.NET Core (совместим с .NET 6/7/8).
База данных: PostgreSQL с маппингом через Fluent API.
Инструменты: AutoMapper (для маппинга DTO), Swagger (для документации API).
Middleware: Глобальный обработчик ошибок для перехвата исключений и возврата структурированных ответов.

Особенности реализацииГибкость маршрутизации: Использование атрибутов [Route] и [ApiController] для настройки эндпоинтов, таких как /api/nutrition/report/{reportId}.
Оптимизация данных: Репозитории загружают только необходимые данные (например, GetNutrientsByReportIdAsync вместо полного NutritionReport).
Обработка ошибок: Глобальный middleware перехватывает исключения и возвращает JSON-ответы с кодом состояния и сообщением.
Конфигурация: Модель данных настроена в OnModelCreating с учётом связей (например, HasOne/WithMany) и seed-данных для ContentTemplate.
